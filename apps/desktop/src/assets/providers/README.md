# Provider icons

Original provider-owned assets, retrieved September 26, 2026. These are bundled
with the renderer; displaying a provider does not contact an external image host.
Preserve their artwork, colors, proportions, and the provided light/dark variants.
Provider names remain visible alongside these decorative icons. Logos identify
connections and do not imply endorsement. The marks belong to their owners.
