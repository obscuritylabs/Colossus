## Maintain the references

Updates are deliberate repository changes, not runtime downloads. Compare the linked
source pages with each relevant summary, check the upstream license notice, revise
only affected topics, and update the review date and change description here. Keep
the entry point short and its topic paths current. Preserve source attribution and
include any new upstream exceptions before redistributing content. Validate the
plugin and run the bundled-plugin and runtime documentation-policy tests.

Installed content follows normal plugin versions and immutable run snapshots. Update
Colossus to update the bundled copy; update or reaccept a separate package/source
through the existing plugin lifecycle. Reading guidance never updates an installation.
